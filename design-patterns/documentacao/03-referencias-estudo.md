# 📚 Referências de Estudo - Design Patterns

## 📖 Livros Essenciais

### 🏆 **Design Patterns: Elements of Reusable Object-Oriented Software**
**Autores**: Gang of Four (Gamma, Helm, Johnson, Vlissides)  
**⭐ Nível**: Intermediário/Avançado  
**📝 Descrição**: O livro clássico que definiu os 23 padrões fundamentais  
**🎯 Por que ler**: Base teórica sólida, exemplos em C++ e Smalltalk  

### 🌟 **Head First Design Patterns**
**Autores**: Eric Freeman, Elisabeth Robson  
**⭐ Nível**: Iniciante/Intermediário  
**📝 Descrição**: Abordagem visual e didática para aprender padrões  
**🎯 Por que ler**: Fácil de entender, exemplos em Java, humor e ilustrações  

### 🔧 **Refactoring: Improving the Design of Existing Code**
**Autor**: Martin Fowler  
**⭐ Nível**: Intermediário  
**📝 Descrição**: Como aplicar padrões durante refatoração  
**🎯 Por que ler**: Ensina quando e como aplicar padrões na prática  

### 🏗️ **Clean Architecture**
**Autor**: Robert C. Martin (Uncle Bob)  
**⭐ Nível**: Intermediário/Avançado  
**📝 Descrição**: Padrões arquiteturais e princípios de design  
**🎯 Por que ler**: Contexto mais amplo de onde os padrões se encaixam

## 🎯 **Roteiro de Estudos Sugerido**

### 📅 **Semana 1-2: Fundamentos**
- [ ] Ler documentação básica (fundamentos)
- [ ] Assistir 2-3 vídeos introdutórios
- [ ] Explorar Refactoring.Guru

### 📅 **Semana 3-4: Padrões Criacionais**
- [ ] Estudar Singleton, Factory, Builder
- [ ] Implementar exemplos práticos
- [ ] Fazer exercícios propostos

### 📅 **Semana 5-6: Padrões Estruturais**
- [ ] Estudar Adapter, Decorator, Facade
- [ ] Refatorar código existente aplicando padrões
- [ ] Criar projetos exemplo

### 📅 **Semana 7-8: Padrões Comportamentais**
- [ ] Estudar Observer, Strategy, Command
- [ ] Implementar sistema completo usando múltiplos padrões
- [ ] Revisar e consolidar conhecimentos

### 📅 **Semana 9+: Prática Avançada**
- [ ] Ler "Head First Design Patterns"
- [ ] Contribuir para projetos open source
- [ ] Criar seus próprios exemplos e tutoriais
