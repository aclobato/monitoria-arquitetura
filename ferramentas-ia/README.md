# 🤖 Ferramentas de IA para Desenvolvimento

Este agrupamento cobre ferramentas e metodologias que utilizam **Inteligência Artificial** para melhorar o processo de especificação, planejamento e desenvolvimento de software.

|---|---|---|
| 🔧 [spec-kit](./spec-kit/) | Spec-Driven Development com GitHub Copilot | ✅ Disponível |
| 🧰 [harness-engineering](./harness-engineering/) | O que compõe um agente de IA além do modelo — guides, sensores e hooks | ✅ Disponível |

## 💡 Por Que Ferramentas de IA?

O uso de IA no desenvolvimento de software deixou de ser opcional e passou a ser uma **vantagem competitiva real**. Mas usar IA de forma eficiente vai muito além de simplesmente digitar prompts — exige metodologia, estrutura e boas práticas.

Este agrupamento cobre abordagens que transformam o uso de IA de **reativo** (pedir correções e trechos de código) para **proativo** (usar IA como parceiro de especificação e desenvolvimento estruturado).

## 🗺️ Como Navegar

Cada ferramenta segue a estrutura padrão do repositório:

```
ferramenta/
├── documentacao/    # Conceitos e guias teóricos
├── exercicios/      # Prática guiada com objetivos claros
└── codigo-exemplo/  # Artefatos e exemplos prontos para referência
```

`harness-engineering` é um tópico com subdivisões — a mesma estrutura se repete uma vez para cada subdivisão (`guides/`, `sensores/`, `hooks/`); veja `harness-engineering/README.md` para o índice completo.
