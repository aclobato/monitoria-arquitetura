## 🗺️ Progressão

Os exercícios foram desenhados para serem feitos em ordem:

```
Exercício 1          Exercício 2              Exercício 3
─────────────        ─────────────────        ──────────────────────
Instalar e           Usar specify +           Ciclo completo:
configurar o         Copilot para             specify → plan →
spec-kit             especificar uma          tasks → implement
                     feature real
```

## ✅ Pré-requisitos Gerais

- VS Code instalado com a extensão **GitHub Copilot** ativa
- Acesso ao **GitHub Copilot** (plano individual ou organizacional)
- Terminal (PowerShell ou bash)
- Git configurado

## 💻 Código de Apoio

Para os exercícios 2 e 3, você pode usar qualquer projeto existente. Sugestão: use o projeto de Design Patterns (`design-patterns/codigo-exemplo/`) como base — ele já tem uma estrutura conhecida.
