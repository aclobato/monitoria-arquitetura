# 💻 Código de Exemplo — Guides

## 📋 O que tem aqui

Um `CLAUDE.md` de referência para o projeto **MonitoriaBase** (`ferramentas-ia/spec-kit/codigo-exemplo/projeto-base/`), mostrando como aplicar na prática o que os documentos teóricos desta subdivisão descrevem.

## 📂 Estrutura

```
codigo-exemplo/
└── exemplo-guides/
    └── CLAUDE.md    ← guide de referência para o MonitoriaBase
```

## 🎯 Como usar este artefato

### Como referência de qualidade

Compare com o `CLAUDE.md` que você escreveu no Exercício 2:
- Cada seção responde a uma pergunta real (não é documentação genérica)?
- A restrição arquitetural está clara o suficiente para orientar tanto um humano quanto um agente?
- Daria para cortar alguma seção sem perder informação que evita um erro real?

### Como ponto de partida

Se quiser usar esse guide diretamente (comandos a partir da raiz do repositório):

```bash
cp ferramentas-ia/harness-engineering/guides/codigo-exemplo/exemplo-guides/CLAUDE.md \
   ferramentas-ia/spec-kit/codigo-exemplo/projeto-base/CLAUDE.md
```

## 📖 Como Interpretar o Artefato

| Seção do guide | Pergunta que responde |
|---|---|
| Comandos essenciais | Como eu construo/testo isso? |
| Convenções de código | Que padrão a equipe já decidiu seguir? |
| Restrição arquitetural | O que este projeto proíbe? |
| Armadilhas conhecidas | O que já causou erro antes? |
